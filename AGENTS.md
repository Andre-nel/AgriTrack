## Farm Documentation

- Search existing documentation before creating a page.
- Never invent agricultural or veterinary facts.
- Preserve the distinction between observations, farm procedures and references.
- New veterinary claims must have a source and default to draft.
- Never change an approved protocol silently.
- Keep stable page IDs and repair affected links.
- Run the documentation validator and link checker.
- Summarize changed pages, sources and unresolved questions.
